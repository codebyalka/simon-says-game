# Simon Says Game 🎮

A simple Simon Says game built using HTML, CSS, and JavaScript.

## About the Project

Simon Says is a memory-based game where the player needs to remember and repeat the sequence of colors shown by the game. With each level, the sequence becomes longer and more challenging.

## Features

- Random color sequence
- Interactive buttons
- Level-based gameplay
- Visual button animations
- Game Over message
- Score display
- Restart the game after Game Over

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
- setTimeout()

## How to Play

1. Press any key to start the game.
2. Watch the button that flashes.
3. Click the same button.
4. Remember the sequence as the level increases.
5. Click the buttons in the correct order.
6. If you click the wrong button, the game is over.
